不少 VPS 刚安装系统时运行速度都比较快，但随着运行时间越来越长，日志文件、缓存文件以及各种临时数据不断增加，服务器资源占用也会逐渐升高。

对于长期运行的网站、代理服务或者 Docker 环境来说，适当进行系统维护，可以减少磁盘占用，也有助于保持服务器运行稳定。

<!-- more -->

VPS 定期自动清理主要包括几个方面：

- 清理系统缓存；
- 删除临时文件；
- 清理日志文件；
- 删除无用软件包；
- 清理 Docker 镜像和缓存；
- 检查磁盘空间使用情况。

对于运行时间较长的服务器，定期执行这些操作，可以避免磁盘空间越来越小，同时减少部分无用文件对系统造成的影响。

清理步骤一：创建脚本文件： nano /usr/local/bin/clean_vps.sh 粘贴以下内容： #!/bin/bash docker system prune -af apt clean rm -rf /var/log/*.gz /var/log/*.1 /tmp/* 保存并退出（按Ctrl+O →回车→ Ctrl+X） 赋予执行权限： chmod +x /usr/local/bin/clean_vps.sh   步骤二：添加定时任务 运行命令默认设置编辑器为nano： export VISUAL=nano 运行crontab -e 在文件末添加 0 3 * * * /usr/local/bin/clean_vps.sh >/dev/null 2>&1   意为每天清理


除了定期清理之外，平时管理 VPS 也建议尽量集中完成。

例如查看系统信息、查看端口占用、修改主机名、管理用户、查看资源使用情况等，如果每项都需要单独执行命令，会比较麻烦。

更换内核之前，建议先确认当前 VPS 是否支持自定义内核，同时保留原来的启动项，以便出现兼容性问题时能够恢复。

日常维护过程中，也可以定期检查服务器运行状态，例如：

查看磁盘空间：

```bash
df -h
```

查看内存占用：

```bash
free -h
```

查看 CPU 与系统负载：

```bash
top
```

查看当前运行内核：

```bash
uname -r
```

如果服务器部署了网站或者节点服务，还建议定期检查系统更新以及安全补丁。

很多稳定运行几个月甚至一两年的 VPS，往往不是因为硬件问题，而是长期没有维护，导致日志、缓存或者配置越来越复杂，最后影响正常使用。

对于个人博客、小型网站以及代理服务器来说，养成定期清理、定期检查以及备份配置的习惯，比出现故障之后再处理更加省心。
