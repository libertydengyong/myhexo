现在不少商家开始提供这种没有 IPv4 地址的小鸡。

IPv6 only VPS 最大的特点就是价格通常比较低，资源也比较充足，但是使用过程中也会遇到一些问题。

<!-- more -->

平时连接服务器、安装软件、部署服务时，大部分情况下 IPv6 已经够用，但是互联网环境目前还没有完全过渡到 IPv6，仍然有不少服务只支持 IPv4。

之前使用 IPv6 VPS 的时候，就遇到过一些因为网络协议不同导致的问题。有些服务本身没有问题，但是因为目标地址只有 IPv4，IPv6-only VPS 无法直接连接。

给 IPv6 only VPS 添加 IPv4 后，最大的变化就是兼容性提高。

原本只能访问 IPv6 网络的服务器，可以同时访问 IPv4 和 IPv6 资源。

比如安装一些软件、连接第三方 API、访问部分网站时，如果对方只有 IPv4 地址，添加 IPv4 后就可以正常连接。

另外，如果 VPS 用来建站，也会方便很多。

虽然现在 IPv6 用户数量越来越多，但是仍然有很多用户所在网络没有 IPv6。

如果网站只有 IPv6 地址，这部分用户可能无法访问。

增加 IPv4 后，网站可以同时使用 A 记录和 AAAA 记录，让 IPv4 和 IPv6 用户都可以访问。

给 IPv6 only VPS 添加 IPv4 的方式也比较多。

有些商家会提供 IPv4 转发或者 IPv4 出口服务，也有一些方法可以通过脚本实现。

之前测试过一个[又一个IPv6 only的小鸡添加v4的脚本](https://freedomgpt.top/2026/04/30/2026-04-30-003)，主要就是解决 IPv6-only VPS 访问 IPv4 网络的问题。

另外一种情况是不需要给 VPS 增加 IPv4 地址，而是只需要一个 IPv4 出口。

这种方式更适合服务器本身保持 IPv6 环境，但是某些程序需要访问 IPv4 网络的情况。

之前也测试过[为纯IPv6的小鸡添加v4出口，防止送中](https://freedomgpt.top/2026/04/30/2026-04-30-002)，通过增加 IPv4 出口，让纯 IPv6 VPS 在一些网络环境下使用更加方便。

不过 IPv6 only VPS 也不是一定需要 IPv4。

如果只是自己学习 IPv6、测试 Linux 环境，或者运行一些 IPv6 服务，其实单独 IPv6 也完全可以使用。

IPv6 地址数量非常丰富，这也是 IPv6 VPS 的一个优势。

但是如果 VPS 用来搭建网站、运行公开服务，或者需要让更多用户访问，IPv4 和 IPv6 同时存在会更加方便。

添加 IPv4 后也需要注意防火墙设置。

IPv4 和 IPv6 使用不同的网络规则，如果之前只配置了 IPv6 防火墙，需要检查 IPv4 端口是否开放。

DNS 方面也需要对应调整。

IPv4 使用 A 记录，IPv6 使用 AAAA 记录。

实际使用下来，IPv6 only VPS 更像是一种新的网络体验。

对于熟悉 IPv6 的用户来说，它可以降低 VPS 成本，也能体验新的网络环境。

但是目前 IPv4 仍然没有消失，很多场景下 IPv4 依然不可替代。

所以根据自己的用途选择是否添加 IPv4，会比单纯追求 IPv6 或 IPv4 更合。
