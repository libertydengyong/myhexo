3x-ui（也有人写成 3xui）是 [x-ui 原版](https://vpsjq.com/2026/05/08/2026-05-08-001/)（vaxilu维护）停止更新后，由 MHSanaei 接手的社区继任项目，目前仍在活跃维护，协议支持上也比原版全，加了 [VLESS Reality](https://vpsjq.com/2026/08/27/3x-ui-vless-reality/)、[Hysteria2](https://vpsjq.com/2026/08/27/3x-ui-hysteria2/)、MTProto 这些原版没有的东西，新装直接用这个版本就行。

一键安装命令：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

装完终端会直接打印面板地址、端口、用户名、密码和访问路径，记下来。用浏览器打开对应地址，用终端打印的用户名和密码登录。按 3x-ui 官方仓库 main 分支（我读到的是 2026-10-06 的提交）的 `install.sh` 和 `x-ui.sh`，全新安装会随机生成用户名、密码和访问路径（也可以用环境变量 `XUI_USERNAME`、`XUI_PASSWORD` 指定），不是 admin/admin；老版本才用默认的 admin。如果你的面板还在用 admin/admin，登进去第一件事把密码改了，入口在右上角用户名那里。

端口和访问路径可以在面板设置里改。端口改完要记得在服务器防火墙放行，不然面板打不开：

```bash
ufw allow 你的端口号
```

这条命令执行后立刻生效，不需要额外重启或reload ufw。

如果防火墙没问题还是访问不了，大概率是服务商那边的安全组没开端口，去控制面板的防火墙或者安全组手动加一条入站规则。

面板打不开除了端口没放行，还有一种很容易被忽略的情况——**访问路径记错或者输错了**。3x-ui默认会生成一段随机字符串作为访问路径，不是简单的IP+端口就能直接打开面板，完整地址通常是"IP:端口/一串随机路径"这种格式，如果只输了IP和端口、漏了后面的路径，同样会打不开。安装时终端打印的那一整行地址建议直接复制保存，不要凭记忆手动拼。

访问路径建议保留随机字符串，不要改成 /admin 这种，太容易被扫到。

忘记密码的话 SSH 进服务器跑 `x-ui` 打开管理菜单，选“重置用户名和密码”（我读到的 main 分支里是第 7 项，编号随版本会变，以屏幕为准），它会让你输入新的用户名和密码，直接回车则随机生成，**不是**重置成 admin/admin。忘记的是访问路径，则选“重置面板访问路径”（读到的是第 8 项）。Docker 部署的情况稍有不同，具体步骤可以参考[3x-ui忘记密码怎么办](https://vpsjq.com/2026/09/06/3x-ui-forgot-password/)。

如果你在3x-ui和原来的x-ui之间还没想清楚该用哪个，可以看看 [S-UI与3x-ui的对比](https://vpsjq.com/2026/09/06/s-ui-vs-3x-ui/)，两者架构和维护现状差异不小，选型上值得先看一眼。
