![IPv6环境下安装x-ui 2.9.4版](/images/ipv6x-ui-294.webp)

之前使用 VPS 时，大部分服务器还是以 IPv4 网络为主，服务器管理、网站部署以及节点服务通常都会依赖公网 IPv4 地址。

随着越来越多 VPS 开始提供 IPv6 地址，服务器网络环境也发生了一些变化。IPv6 地址数量更加充足，在部分场景下可以直接通过 IPv6 地址访问服务器服务。

这次测试主要关注 IPv6 VPS 环境下安装 x-ui 面板后的访问情况，包括 IPv6 地址检查、端口开放以及面板访问等内容。

安装之前，首先确认服务器是否正常获取 IPv6 地址：

    ip -6 addr

正常情况下可以看到类似：

    inet6 xxxx::xxxx/64 scope global

其中：

    scope global

表示公网 IPv6 地址。

如果只看到：

    ::1

或者：

    fe80::

通常表示当前服务器没有正确配置公网 IPv6。

确认 IPv6 网络正常后，开始安装 x-ui 2.9.4。

x-ui 目前仍然是 VPS 上比较常见的管理面板之一，可以通过面板管理 Xray 服务，包括添加入站、修改端口以及查看运行状态,这里推荐[X－ui2.9.4版本](https://freedomgpt.top/2026/05/08/2026-05-08-001/?highlight=xui)
安装完成后，需要注意 IPv6 环境下访问地址的写法。

IPv6 地址中包含冒号，所以浏览器访问时需要使用中括号。

例如：

    http://[IPv6地址]:端口

而不是：

    http://IPv6地址:端口

否则浏览器可能无法正确识别端口位置。

进入 x-ui 面板后，可以根据服务器情况添加对应配置。

如果服务器只有 IPv6 地址，监听地址可以设置为：

    ::

这样可以监听 IPv6 网络连接。

如果服务器同时存在 IPv4 和 IPv6，则可以根据实际情况选择监听方式。

IPv6 VPS 在运行服务时，与 IPv4 VPS 最大的区别不是软件安装，而是网络访问方式。

除了服务器本身拥有 IPv6 地址，还需要检查：

- 系统防火墙是否开放端口
- 云服务商是否限制 IPv6 入站
- DNS 是否配置 AAAA 记录
- 服务是否监听 IPv6 地址

IPv6-only 环境最大的特点就是所有访问都依赖 IPv6 网络，因此网络连通性检查更加重要。

安装 x-ui 后，可以使用下面命令查看监听情况：

    ss -lntp

如果面板端口没有监听，需要检查 x-ui 服务状态。

同时，如果服务器开启了防火墙，需要放行对应端口。

例如：

    ufw allow 端口

或者根据系统防火墙规则添加 IPv6 端口。

如果使用域名访问 x-ui，还需要配置 AAAA 记录。

例如：

    panel.example.com

解析到：

    2400:xxxx:xxxx::1

如果只设置 A 记录，而服务器没有 IPv4 地址，域名访问会失败。

实际测试下来，IPv6 VPS 安装 x-ui 2.9.4 本身并没有太大区别，主要区别集中在网络配置方面。

只要 IPv6 地址正常、端口开放、DNS 配置正确，x-ui 面板以及相关服务都可以正常运行。
